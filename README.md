# 🛠️ Toolz v3.0

> Advanced System Administration Tool for Linux

---

## ⚡ Features

* 🖥️ System Monitoring (CPU, Memory, Processes)
* 🌐 Network Information & Diagnostics
* 💾 Disk Usage Analysis
* 🔄 Auto Update via GitHub
* 🎨 Clean & colorful terminal UI

---

## 📦 Installation (Linux / Kali / Ubuntu)

### 1. Clone the repository

```bash
git clone https://github.com/00xk/Toolz.git
```

### 2. Enter the directory

```bash
cd Toolz
```

### 3. Give execution permission

```bash
chmod +x tool.sh
```

### 4. Run the tool

```bash
bash tool.sh
```

---

## 🚀 One-line install (quick way)

```bash
git clone https://github.com/00xk/Toolz.git && cd Toolz && chmod +x tool.sh && bash tool.sh
```

---

## 🔄 Update Tool

You can update anytime using:

```bash
cd Toolz
git pull
```

---

## ⚠️ Requirements

Make sure you have:

* git
* curl
* basic Linux tools (ps, df, ip)

Install Git if missing:

```bash
sudo apt install git -y
```

Run the tool and choose from menu:

[3] About
